# Meyo Insights

The public Astro website for Meyo Insights.

**The pursuit of better investment judgment.** A public research journal exploring businesses, industries, markets and the ideas that help us understand them.

This repository contains public website code and explicitly approved articles only. Private financial evidence, source records and unapproved drafts remain in the separate private research repository.

The website is deployed using GitHub Actions to GitHub Pages. Under Settings → Pages, select **GitHub Actions** as the build and deployment source.
